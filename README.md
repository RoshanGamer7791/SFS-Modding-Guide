# SFS Modding Guide (SMG)
The SFS Modding Guide is an unofficial open source, community-driven, documentation project for the video game Spaceflight Simulator (SFS)

SFS Modding Guide 是一个非官方、开源、由社区驱动的《Spaceflight Simulator》（SFS）模组开发文档项目。
